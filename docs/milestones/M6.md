# M6: Currencies

Status: planned

## Goal

Expenses can be in more than one currency, converted at a rate given per expense, with balances in one base currency.

## Exit criteria

1. A ledger has a base currency; an expense may name another currency and a rate to the base.
2. Conversion to base cents happens once per expense, with a stated rounding rule, and the split is done in base cents, so shares add up and balances sum to 0.
3. Rates are parsed as decimals, never floats; a missing or non-positive rate is a `TallyError`.
4. Files from earlier versions load with every expense in the base currency.
5. The full test command passes.

## Not in this milestone

- The rounding rule for conversion (half-even or half-up) and how settlements in a foreign currency work are open questions for `/plan M6`.
