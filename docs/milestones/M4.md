# M4: History

Status: planned

## Goal

Members can see every expense and settlement, and edit or delete one, with balances recomputed.

## Exit criteria

1. Every expense and settlement has a stable id that survives save and load; existing files get ids on load without changing balances.
2. `tally history` lists entries in the order recorded, with id, kind, payer, amount, participants and note.
3. `tally edit <id> ...` and `tally delete <id>` change or remove one entry; balances after the change equal balances of a ledger built without it. Invalid edits change nothing.
4. An unknown id is a `TallyError`.
5. The full test command passes, including the fixture tests from M2.

## Tickets

## Not in this milestone

- Undo, or an audit trail of edits.
- Removing a member.

## Risks and assumptions

- Id format (counter or random) to settle in `/plan M4`; ids must never be reused after a delete.
