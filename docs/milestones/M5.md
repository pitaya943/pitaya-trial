# M5: Export and import

Status: planned

## Goal

The ledger can be written to CSV and read back, for spreadsheets and backups.

## Exit criteria

1. `tally export <file.csv>` writes members, expenses (with split kind) and settlements.
2. `tally import <file.csv>` into an empty ledger gives the same entries and the same balances as the original: a round-trip test over random ledgers.
3. A malformed CSV is rejected with a `TallyError` naming the row; nothing is imported.
4. Amounts in the CSV use the same text form as the CLI (`12.50`), parsed by `parse_amount`.
5. The full test command passes.

## Not in this milestone
