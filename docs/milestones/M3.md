# M3: Unequal splits

Status: planned

## Goal

An expense can be split by exact amounts, by percentages, or by shares (2:1:1), not only equally.

## Exit criteria

1. Exact amounts: the amounts must add up to the expense amount, or it's a `TallyError` and nothing is recorded.
2. Percentages must add up to exactly 100; shares must be positive integers.
3. Percentage and share splits use the largest remainder method: floor every share, give leftover cents to the largest fractional parts, ties in listed order. Equal splits give the same result as today. See ADR 0002.
4. For every split kind, shares add up to the expense amount and balances sum to 0. Checked by property tests.
5. The CLI accepts the new split kinds, and v0.1 and v2 files without a split kind still load as equal splits.
6. The full test command passes.
